# Tic-Tac-Toe | Python Game

## Overview

This repository hosts a simple, terminal-based Tic-Tac-Toe game, crafted entirely in Python. It's a foundational project that marks my initial foray into Python programming, showcasing basic concepts like functions, loops, conditional statements, and user input handling.

---

## Features

* **Two-Player Gameplay:** One can enjoy classic Tic-Tac-Toe with a friend.
* **Terminal Interface:** Play directly in your command line without any graphical UI.
* **Input Validation:** Ensures players enter valid moves.
* **Win Condition Detection:** Automatically checks for a winner after each move.
* **Draw Detection:** Identifies when the game ends in a tie.

---

## How to Play

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Codexadi25/Tic-Tac-Toe.git
    cd Tic-Tac-Toe
    ```

2.  **Run the game:**
    ```bash
    python Tic_Tac_Toe.py
    ```

3.  **Follow the prompts:** The game will guide you through making moves by entering the number corresponding to the desired board position (1-9).
